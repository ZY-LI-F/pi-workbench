# 本轮生成要求

用户原话：“不用pi，直接你来调用paper2any”。沿用“生成、不再使用 DeepSeek”的要求。

本轮直接由当前 Codex 主代理整理 MoleculeNet 论文与既有实验结果，生成新的 Paper2Any Canvas 页面结构，调用隔离源码中的 `buildCanvasSlidesPptxBlob` 导出 PPTX。不调用 Pi，不读取 Pi 配置或密钥，不调用外部模型 API，不开启子代理。

该路线使用 Paper2Any 的真实 Canvas 导出器，但不执行其外部模型大纲/页面生成服务。此区别须在交付说明中明确，不把之前失败的 API 链路改写成成功。

默认内容：14 页中文科研组会说明，16:9，覆盖论文、数据、固定实验协议、结果、数据纠正、局限与来源。模板已在前一轮选择器中取消，本轮延续简洁学术风格。

使用已完成的 48 次真实训练/评估数据，不重新训练，不使用上一轮由 DeepSeek 生成的大纲、页面或 PPT。实验数值来自 DeepChem 及独立审计，保留其历史来源。不把 3 数据集的局部复现说成 17 数据集全量复现。

文件只写入本轮独立输出目录，保留用户业务代码与上一轮证据。
