# MoleculeNet 局部复现说明

## 成品

- `MoleculeNet-Paper2Any-局部复现说明.pptx`：14 页中文、16:9 演示文稿。
- `notes.md`：逐页讲稿与文献来源，也已写入 PPTX 的演讲者备注。
- `slides.md`：可阅读的逐页内容副本。
- `refs.md`：论文、图片许可与既有实验文件索引。

文字与 7 张数据表为可编辑的 PowerPoint 原生对象；2 幅论文原图为嵌入图片。
字体为 Noto Sans SC。其他电脑没有该字体时，Office 可能替换中文字体，排版可能略有变化。

## 本轮如何使用 Paper2Any

本轮按“不要使用 Pi，由当前代理直接调用 Paper2Any”的要求执行。

1. 当前 Codex 主代理依据论文和已核验实验结果，新写内容、讲稿与 Paper2Any Canvas 页面结构。
2. 直接调用 Paper2Any 源码中的 `buildCanvasSlidesPptxBlob`，真实导出可编辑 PPTX。
3. 补入讲稿、文献引用及文件元信息。导出包出现了 13 条不存在且未被引用的母版声明，已清理这些失效声明。原始导出保留在 `../build/`。
4. 最终文件保留了原生导出全部 14 页的 slide XML，未用另一套制版代码重绘或替换。

本轮没有调用 Pi、没有读取 Pi 密钥、没有调用 DeepSeek 或其他外部模型 API，也没有复用上一轮语言模型生成的大纲或幻灯片。

**准确的路线是“当前 Codex 生成页面内容与结构 + Paper2Any 原生 Canvas 导出”。没有执行 Paper2Any 自带的外部模型大纲/页面生成服务，不代表之前失败的接口链路已恢复。**

## 科学范围

本报告沿用 2026-09-18 已完成的 48 次 DeepChem 实验，不代表本轮重新训练。历史实验曾由 Pi 与 DeepSeek 协助编排，该历史来源保持原样，不因本轮换生成方式而删除。

范围为 3 个完整数据集和 4 类模型，属于论文局部复现，未完成 17 个数据集、全部算法、原环境、原始分区及超参数搜索的全量还原。PPT 保留 FreeSolv 负结果、ESOL 重复结构交叉和数据单位纠正，不构成靶点、湿实验或临床有效性证据。

## 复运行本次导出

本机入口为 `../build/generate.ts`，通过项目现有 tsx 调用；它需要已检出的固定 Paper2Any 源码与原实验汇总文件。后续 `finalize.mjs` 补充备注并验证打包，`render.mjs` 渲染最终成品。绝对路径记录在脚本中，迁移电脑时需要改为实际目录。

只重新导出内容时不需要 API Key 或 Pi。修改后应使用新的最终文件名，保留历史报告。
