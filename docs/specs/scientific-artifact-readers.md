# 科研产物阅读器 · Spec

状态：已实现并通过 Windows 本机验收。2026-09-19。依据：[Paper2Agent 产物研究](../research/paper2agent-artifact-preview-2026-09-19.md)。证据：[验收记录](../testing/scientific-artifact-readers-2026-09-19.md)。

## 目标与边界

补齐研究建议第一、第二优先级的六项能力，使用户能在「检查器 → 文件」连续阅读论文包、实验数据与代码证据。只有一套官方 Pi；阅读不请求模型、不启动 Python/Jupyter/MCP、不执行文档脚本，不安装 Office 插件。本轮不包含分子三维查看、交互式任意 HTML、二进制科学数据、MCP 注册或云端发布。

## 阅读路径

1. 保留会话文件下拉。新增「产物目录」弹层，选择本机目录，按目录进入、返回上一级，搜索当前目录并按类别筛选；目录和文件的磁盘修改时间与会话最后提及时间明确区分。
2. 提供正文、补充材料、图、表、原始 PDF、验证记录的分类/导航。关联证据目录不改变当前项目，不授予执行信任。文件夹里的文件无需先被助手提及即可打开。
3. 关闭目录弹层后保留整个右栏给预览。相对链接进入相应阅读器，返回按钮回到原文件与原滚动位置。图片、表格、代码、JSON 和 Notebook 都沿用引用到聊天、刷新、复制路径与所在位置。
4. 打开另一文件时不强制把已经拖窄的检查器重新放大。会话切换隔离当前阅读链，保留已有 session 文件恢复行为。

## 六项功能的验收条件

### AR-01 目录与资源边界

- 主进程提供只读目录列表及本地链接解析；所有入口验证主窗口来源、参数、规范路径、实际文件类型和授权目录。
- 用户通过原生文件夹选择器授权额外只读产物目录；该授权只存在于本次应用进程，不写入项目执行信任。取消选择不改变现有目录。
- 额外授权绑定选择时的规范目录。目录随后被 junction/symlink 重定向时，新目标不继承旧授权；用户重新选择才可授权新的实际位置。
- 列表按需读取单层，不自动扫描虚拟环境或整个硬盘；搜索明确标为当前目录。目录导航不截断条目，采用显式分页。权限失败、已删除文件及越界符号链接显示具体错误，不伪装空列表。
- 支持 `../assets/…`、中文、空格和 URL 编码；链接和图片不可跳出已授权目录，也不可访问 UNC 或任意 URL 协议。PDF `#page=N` 只接受文件中明确提供的正整数页码，不从文件名猜页码。

### AR-02 学术 Markdown

- 保留 GFM 表格与脚注，增加公式、章节目录和锚点跳转；重名标题有稳定且唯一的锚点。
- 本地图像经主进程读取并生成只读资源；网络图片仍不自动加载。相对 Markdown、图片、CSV、PDF 链接在检查器内打开；HTTP(S) 链接沿用受控外链入口。
- SVG 保留普通样式、本地渐变和内嵌位图，移除脚本、事件、foreignObject 与外部资源，避免把合法科研图中的热图或颜色样式一起删除。
- 返回正文恢复滚动位置。缺失资源必须显示失败原因。原文内 HTML 不作为可执行 DOM 注入。

### AR-03 CSV / TSV

- 从纯文本升级为表格，默认不推断/改写数值类型，正确处理 BOM、引号、嵌入换行、空字段、空行、前导零和长 ID。
- 可切换是否使用第一行表头、选择编码、搜索、按列筛选和显式文本/数值排序、冻结首列、分页；原始文本始终可查看。
- 数值排序不能改写展示值，不把混合文本静默转成 0。解析错误及编码错误明确显示；以 `=` 开头的单元格只显示文本。

### AR-04 JSON 与验证报告

- 通用 JSON 折叠树、搜索、原始文本视图；无效 JSON 明确报错，不冒充空对象。
- Paper2Skill 验证摘要按官方状态区分机械失败、未复核、未解决差异、已复核有限制、已复核。缺失字段显示未记录，不猜成通过。
- 展示机械校验、文档审阅状态、issues 与 scope/限制说明；保留原始证据。`mechanical_ok` 不是科学复现结论。
- 文件路径可导航；`artifact_checks[].file` 相对已关联产物目录解析，外部证据路径相对当前报告解析，不根据近似目录名猜测。

### AR-05 只读 Notebook

- 支持 nbformat 4、Markdown/raw/code 单元，兼容字符串和字符串数组，代码折叠、执行序号、stdout/stderr、错误堆栈、保存的表格/图片/公式输出与 cell attachments。
- 无输出显示「未保存输出」；未知 MIME 明确列出并提供原始数据，不以空白或模板冒充成功。Notebook 的历史输出不被声明为本次运行结果。
- HTML 输出隔离，脚本/联网/表单禁止；不加载 widget 内核或 Python 环境。结构无效时提供错误及原文，不执行任何单元。

### AR-06 源码与 MCP 说明

- `.py`、`.r`、`.sh`、`.ps1`、JS/TS 等只读高亮、行号、搜索/跳转；代码复制保留原文。
- `USAGE.md` 使用学术 Markdown；工具 schema/验收 JSON 使用结构化阅读器。预览不会 import 模块、安装依赖或启动 MCP 服务。
- MCP ZIP 不含开发证据不视为错误；本轮读取已解压的目录，不自动解压或安装代码包。

## 架构

- `shared`：文件类型、目录与本地链接的扁平 IPC 契约。
- `main`：依赖注入的目录/链接服务，复用现有 canonical path 授权与文件读取；授权只能由原生目录选择器增加。
- `renderer/lib`：表格、Notebook、验证报告的纯解析/投影；渲染组件按职责拆分，按需加载数学/高亮等库。
- `FilePreviewPanel`：文件选择、阅读链、资源定位和统一操作，不承担各格式的全部解析。
- 安全规则为现有只读隔离边界的延伸；不增加任务回合上限、静默降级、截断结果或执行成功假数据。

## 验证

参数与路径安全单测、真实文件读取测试、各格式边界单测、组件键盘/切换/错误测试，完整 `npm run check` 与生产构建。Electron E2E 使用明确标记的阅读夹具验证六项阅读路径、取消授权、无代码执行、窄栏与返回位置；原有原生 GUI 回归不得退化。已有真实 Paper2Skill 样本用于补充可视化检查，不覆盖或改写原产物。
