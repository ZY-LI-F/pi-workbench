## 验收中修正的测试问题

- 长会话夹具最初写入自定义 session 目录，改用 Pi 按项目编码的正常目录；从配置页面返回时补齐「任务栏」页签步骤。
- 统计用例最初无条件按 Ctrl+I，把已展开的检查器关闭；改为只在未展开时打开，再检查上下文统计。
- 80 条历史 Markdown + 40 次流式更新的复杂度测试，在本机出现 7–10 秒执行时间。保留 81 次初始解析、40 次增量解析和 81 个节点的所有断言，将该测试等待时间从 5 秒改为 20 秒；它不再把 jsdom 墙钟时间误当作性能预算。未更改业务超时或任务运行限制。
- 一次全量运行中的真实 Git worktree 测试超过默认 5 秒；单独串行复核通过，未修改该功能及其断言。
- 新增停止失败用例起初预期 `success:false` 返回值；官方响应在运行时已转换为拒绝异常，修正为断言异常且不得出现成功停止通知。

## 边界与未验证项

- Windows 验收不代表 macOS 实机验收；macOS CLI 符号链接用例在 Windows 跳过，POSIX 进程监管未在 macOS 实机运行。
- 后台停止管理**由新版本 Pi 运行实例启动的本机子进程**；不追溯接管旧实例，不承诺取消 SSH、容器、外部服务或主动清除继承标记的进程。运行中使用输入区停止；空闲时仍可在检查器「活动」点击「停止 Pi 与后台计算」。
- 本轮验证长历史恢复、连续工具执行、压缩、统计刷新、终止及恢复交互，不把它扩大表述为任意时长、任意模型长任务稳定性均已通过。
- PPT 是只读内容预览，不执行宏/动画，复杂排版不承诺与 PowerPoint 像素级一致；PDF 扫描页无文字时明确提示未做 OCR。
- 本轮没有生成新安装包、提交、推送、创建 Tag 或发布 Release；已有用户窗口和原始会话不作替换。
